# Next.js Dashboard Tutorial

Proyecto desarrollado siguiendo la **ruta de aprendizaje oficial de Next.js** ([nextjs.org/learn](https://nextjs.org/learn)). El tutorial guía paso a paso en la construcción de un dashboard completo, cubriendo los conceptos fundamentales del framework.

## 🚀 Cómo empezar

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

## 📚 Conceptos cubiertos

- Enrutamiento basado en archivos con el App Router
- Server y Client Components
- Estrategias de fetching y caché de datos
- Rutas dinámicas y layouts anidados
- Estilos con Tailwind CSS
- Autenticación básica

## 🛠 Stack tecnológico

- **Framework:** Next.js 14+
- **Estilos:** Tailwind CSS
- **Base de datos:** (p. ej. PostgreSQL / SQLite)
- **Autenticación:** NextAuth.js
